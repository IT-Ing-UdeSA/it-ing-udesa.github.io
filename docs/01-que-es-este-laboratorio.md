# Maquinas

## Equipamiento

El laboratorio cuenta con 22 maquinas de uso general, las cuales son compartidas entre materias y poseen la capacidad de conexion remota.


| Componentes                    | Tipo                     |
|--------------------------------|--------------------------|
|          **Processor**         |   Intel Core i7 14800k   |
|             **GPU**            | NVIDIA GeForce RTX 4090  |
|      **RAM per Core (GB)**     |           32GB DDR5      |
|       **Discos locales**       |   1TB NVME (Linux) + 256GB SSD (Windows)  |
|      **Sistema Operativo**     |      Ubuntu 24.04.5      |
