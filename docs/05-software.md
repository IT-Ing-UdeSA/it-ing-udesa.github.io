# Software 

## Software instalado en el sistema

Los siguientes programas están instalados de forma global y se pueden usar directamente, sin cargar ningún módulo.

| Categoría | Programas | Uso |
|---|---|---|
| Monitoreo | `nvtop`, `btop` | Uso de GPU, CPU y RAM de la máquina |
| Sesiones remotas | `tmux` | Varias terminales dentro de una misma conexión SSH |
| Transferencia de archivos | `rsync`, `curl`, `wget` | Copiar datos desde y hacia la máquina |
| Desarrollo | `git`, `build-essential`, `cmake` | Control de versiones y compilación |
| Python | `python3-venv`, `python3-dev`, `uv` | Entornos virtuales (Se recomienda crearlos en `~/scratch/work/`) |
| GPU | CUDA toolkit | Compilar y correr código en la GPU |
| Archivos | `tree`, `zip`, `unzip`, `p7zip` | Navegar y comprimir archivos |
